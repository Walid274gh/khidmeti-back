# OBJECTIF : donner au LM les BIGRAMMES/TRIGRAMMES qui lèvent l'ambiguïté
# acoustique des paires métier×symptôme, pour TOUTES les professions, avec des
# VARIANTES ORTHOGRAPHIQUES (le darija n'a pas de graphie unique : plusieurs
# écritures du même mot = plus de matches au décodage).
#
# Cas terrain mesurés qui ont motivé ce fichier :
#   «الضوء راه مقطوع» entendu «دور مقطوع» → mécanicien au lieu d'électricien :
#   les deux bigrammes étaient ABSENTS du LM (lm_logp identiques). Le contraste
#   est maintenant VÉRIFIÉ : الضوء مقطوع ≫ دور مقطوع.
#   «لافابو راها خاسرة الماء راه غي يسيل» → 0 % : «خاسرة» était OOV et le
#   bigramme absent. «روبنيه» aussi OOV — ajoutée ici avec ses variantes.
#
# RÈGLES : chaque phrase = forme naturelle d'un utilisateur (jamais de liste de
# mots) ; chaque bigramme discriminant répété 2-4× pour min_count=2 ; contexte
# de PIÈCE ajouté (المطبخ/الحمام/الصالون…) pour désambiguïser les confusions
# phonétiques (الضوء/دور, يسيل/سيل, خاسر/قاسر…) ; code-switch conservé.
# ⚠️ NE PAS éditer à l'aveugle : toute phrase biaise le faisceau vers ses paires.
